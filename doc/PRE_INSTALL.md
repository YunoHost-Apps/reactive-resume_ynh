Reactive Resume requires a **dedicated domain or subdomain** (for example `cv.example.com`): it cannot be installed in a sub-path.

The app is built on your server during installation and upgrades. This needs about **4 GB of RAM** (swap included) and **3 GB of disk space**, and takes several minutes.

Reactive Resume has its **own user accounts**, which are not linked to YunoHost users (no LDAP nor SSO).
